# Автотесты формы заказа доставки карты (перепланирование встречи)

## Запуск
1. Запустить SUT: `java -jar artifacts/app-replan-delivery.jar`
2. Запустить тесты: `./gradlew test` (в Windows: `gradlew.bat test`)
